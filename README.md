# SciTech Hub

A science and technology discovery platform described in the original project as a place where ideas and investors meet. The React application organizes research, companies, community profiles, events, tenders, and articles into browsable views.

## Interface and architecture

- Dedicated list and detail pages for scientific and community content.
- Search controls, filters, reusable cards, tables, and navigation.
- React components with Redux state management and React Router navigation.
- JavaScript, SCSS, Webpack, and a Node.js server entry point.

## Explore the code

- [src/index.js](src/index.js): application routes and composition.

- [src/actions](src/actions/) and [src/reducers](src/reducers/): state and data-flow logic.
